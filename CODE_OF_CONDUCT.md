# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, welcome newcomers, and keep discussions about the
work. Harassment, insults and personal attacks are not tolerated, in any project space.

To report unacceptable behaviour, contact the maintainers privately through the email address of the
maintainer's GitHub profile, or through GitHub's report feature. Reports are handled confidentially.
